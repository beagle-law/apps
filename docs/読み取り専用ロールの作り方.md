# 読み取り専用ロール（Claudeの分析用）の作り方

Claudeがデータの検索・分析をするときに使う、**読み取りしかできない**データベースのユーザーを、Neonで作ります。
このユーザーなら、操作を間違えても、データの変更・削除はできません。

## 1. Neonでロールを作る
1. https://console.neon.tech でプロジェクトを開き、左メニューの **SQL Editor** を開く（ブランチ `main`、データベース `neondb`）。
2. 次のSQLを、**パスワードの部分を自分で決めた長い英数字に変えて**実行する（英数字32文字以上。記号は避ける）。

```sql
CREATE ROLE claude_readonly WITH LOGIN PASSWORD 'ここに英数字32文字以上';
GRANT CONNECT ON DATABASE neondb TO claude_readonly;
GRANT USAGE ON SCHEMA public TO claude_readonly;
GRANT SELECT ON ALL TABLES IN SCHEMA public TO claude_readonly;
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT SELECT ON TABLES TO claude_readonly;
```

3. 最後の行は、今後追加される表も自動で読み取れるようにするための設定です。ただし、`neondb_owner` が作る表だけが対象です（このアプリのマイグレーションは `neondb_owner` で実行しているので、問題ありません）。

## 2. 接続文字列を作る
本番の接続文字列（`postgresql://neondb_owner:…@ep-…-pooler…/neondb?sslmode=require…`）の、**ユーザー名とパスワードの部分だけ**を差し替えます。

```
postgresql://claude_readonly:（手順1で決めたパスワード）@ep-green-frost-aoqh1ab5-pooler.c-2.ap-southeast-1.aws.neon.tech/neondb?sslmode=require
```

## 3. 自分のPCにだけ保存する
プロジェクトのフォルダ `C:\Users\taish\Desktop\APP` に、`.env.readonly` というファイルを新しく作り、次の1行だけを書いて保存します。

```
DATABASE_URL_READONLY="手順2の接続文字列"
```

- このファイルは gitに入りません（`.gitignore` の `.env*` の対象）。
- **接続文字列やパスワードは、チャットには貼らないでください。**

## 4. 動作確認
```
node scripts/ro-query.js "SELECT count(*) AS cases FROM \"Case\""
```
件数が出れば成功です。書き込みを試すと、エラーになります。

## 注意
- 暗号化されている列（顧客の個人情報・パスワード管理）は、暗号文のまま返ります。復号用の鍵は、このスクリプトでは使いません。
- パスワードを変えたいときは、Neonの SQL Editor で `ALTER ROLE claude_readonly WITH PASSWORD '新しいもの';` を実行し、`.env.readonly` を書き換えます。
