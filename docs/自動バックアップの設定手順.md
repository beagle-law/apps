# 自動バックアップの設定手順

毎日 0:00（日本時間）に、アプリの全データを JSON ファイル 1 つにまとめて、Box の次のフォルダへ保存します。

`...\00.総務資料\00.ノウハウ・ひながた・TMI\30.Beagleアプリバックアップ`

- ファイル名：`beagle-backup_YYYY-MM-DD.json`（同じ日に再実行した場合は、同名ファイルの新しいバージョンとして保存）
- 保存期間：30日分（それより古い `beagle-backup_*.json` は自動で削除。ほかのファイルは削除しません）
- 管理者の「設定」画面の「自動バックアップ」で、実行結果の確認と「今すぐバックアップ」ができます。

## 含まれるもの

案件（備考・タイムライン・タスク含む）、顧客（復号済み）、タイムチャージ、勤怠、日報、パスワード管理（カテゴリ・復号済み＝**平文**）、
目標、ノウハウ（画像・ひながたは名前などの情報のみ）、請求書、案件の分類、月ごとのメモ、お金の情報カード、ユーザー情報、操作履歴。

## 含まれないもの

- 添付ファイル・画像・ひながたの**ファイル本体**
- 個人メモ（本人以外には見せない設計のため）
- ログイン用パスワード（ハッシュ）
- 個人メモの案件（非公開の案件）

## 設定手順（最初の1回だけ）

### 1. Box でアプリを作る
1. Box の開発者コンソール（https://app.box.com/developers/console）を開く
2. 「アプリを作成」→「カスタムアプリ」→ 認証方法は **「サーバー認証（クライアント資格情報許可）」**
3. アプリ名は「Beagleアプリバックアップ」など
4. 「構成」タブで、アプリのアクセスレベルは「アプリ + エンタープライズアクセス」、アプリケーションスコープは **「Read and write all files and folders stored in Box」** を有効にして保存
5. 「構成」タブの「クライアントID」「クライアントシークレット」と、「全般設定」の「エンタープライズID」を控える

### 2. Box の管理者にアプリを承認してもらう
Box 管理コンソール → アプリ → カスタムアプリ → 「新しいアプリを承認」で、上のクライアントIDを入力して承認する。

### 3. 保存先フォルダにアプリを招待する
1. 開発者コンソールの「全般設定」にある「サービスアカウント」のメールアドレス（`AutomationUser_...@boxdevedition.com`）を控える
2. Box で保存先フォルダ（30.Beagleアプリバックアップ）を開き、共有 → そのメールアドレスを **「編集者」** として招待
3. そのフォルダを Box のWeb画面で開いたときのURL末尾の数字（`.../folder/123456789`）が **フォルダID**

### 4. Vercel に環境変数を入れる
Vercel → プロジェクト → Settings → Environment Variables に次の5つを追加（Production）。

| 名前 | 値 |
| --- | --- |
| BOX_CLIENT_ID | 手順1のクライアントID |
| BOX_CLIENT_SECRET | 手順1のクライアントシークレット |
| BOX_ENTERPRISE_ID | 手順1のエンタープライズID |
| BOX_BACKUP_FOLDER_ID | 手順3のフォルダID |
| CRON_SECRET | ランダムな長い文字列（例：パスワード生成ツールで32文字以上） |

追加後、**再デプロイ**（Deployments → 最新の「…」→ Redeploy）すると有効になります。

### 5. 動作確認
アプリの「設定」→「自動バックアップ」で「Box連携」「毎日の自動実行」が両方「設定済み」になっていることを確認し、
「今すぐバックアップ」を押して、Box のフォルダにファイルができればOKです。

## 注意
- Vercel の無料（Hobby）プランでは、定時実行の時刻が「0:00 ちょうど」ではなく**0:00〜0:59 の間**になることがあります。
- 保存されるファイルには、パスワード管理の内容が**平文**で含まれます。フォルダのアクセス権限を制限したままにしてください。
- Box のゴミ箱にも30日分の削除済みファイルが残ります（Box側の設定による）。
